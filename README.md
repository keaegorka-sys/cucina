# Cucina — итальянский рацион на неделю

Личный планировщик итальянской кухни: проходишь короткий квиз — получаешь меню на каждый день, пошаговые рецепты, список покупок с примерными ценами и карту кулинарных навыков.

**Открыть:** https://keaegorka-sys.github.io/cucina/

## Что умеет

- **Квиз из 10 шагов** — тип питания, аллергии и «не люблю», свайп блюд «нравится / не моё», сколько человек, приёмы пищи, калории, бюджет, кухонная техника, уровень и время на готовку.
- **Калькулятор нормы калорий** — в шаге «Калории» можно ввести пол, рост, вес, возраст, активность и цель (похудеть, держать вес, набрать). Считается по формуле Миффлина — Сан-Жеора. Для взрослых 18–80 лет; нижний предел 1200 ккал для женщин и 1500 для мужчин, при низком ИМТ худеть не предлагает. Это оценка, а не медицинская рекомендация.
- **Меню на 3, 5 или 7 дней** — завтрак, обед, ужин и «проект выходного» (фокачча, тирамису, соус маринара). По-итальянски: на обед — primo (паста, ризотто, суп), на ужин — secondo.
- **Порции под норму калорий** — если блюда в какой-то день лёгкие, порции увеличиваются, а продукты пересчитываются.
- **Ужин с запасом** — двойная порция вечером становится обедом на следующий день.
- **Замена блюд** — ↻ подобрать другое или ☰ выбрать из подходящих.
- **Список покупок в METRO** — для каждого продукта подобран конкретный товар интернет-магазина METRO (online.metro-cc.ru) с ссылкой и ценой. Покупка — целыми упаковками, весовые овощи — целыми штуками. Видно, сколько платишь, сколько съешь за неделю и что останется в запасе.
- **Таймеры при готовке** — если в шаге рецепта есть время («туши 10–12 минут»), рядом кнопка ⏱: запускает обратный отсчёт. Несколько таймеров одновременно, пауза, +1 минута, свой таймер; по окончании — звук, вибрация и «Готово!». Пока таймер идёт, экран не гаснет (где браузер это разрешает).
- **Без дробей** — в рецептах вместо «½ луковицы» и «¾ пучка» — граммы или целые штуки, ложки целые.
- **Практика** — в каждом рецепте указано, какой технике он учит; в будни блюда по уровню, в выходные — на шаг сложнее. Отмечай приготовленное, ставь оценку и заметки.
- **Экономные замены** — твёрдый сыр вместо пармезана, ветчина вместо прошутто и т. п. (около −20% к бюджету).

Всё работает в браузере, без сервера и регистрации. Настройки, меню и прогресс хранятся только в браузере на твоём устройстве.

## Запуск на компьютере

Скачай репозиторий и открой `index.html` двойным щелчком — интернет нужен только для шрифта.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Приложение: квиз, генератор меню, покупки, рецепты, прогресс |
| `recipes.js` | Базовая коллекция: 43 классических итальянских рецепта |
| `recipes-book.js` | 32 блюда по мотивам книги Giada De Laurentiis «Everyday Italian» |
| `recipes-kd.js` | 14 итальянских блюд по мотивам книги Nick DiGiovanni «Knife Drop» |
| `metro.js` | Конкретные товары METRO под каждый ингредиент: артикул, ссылка, фасовка, цена (на 6 ноября 2026, самовывоз просп. Мира, 211) |
| `prices.js` | Запасные примерные цены — используются, если для продукта нет товара METRO |
| `tools/build-artifact.py` | Собирает версию для ссылки Claude из `index.html` |

Цены METRO меняются. Чтобы обновить их, попроси Claude пройтись по сайту METRO ещё раз — товары и фасовки перечитаются в `metro.js`.

Товары, которых в METRO не нашлось, заменены ближайшими: пекорино → пармезан, телячья голяшка → говяжья, фонтина → гауда, фарфалле и трофие → фузилли, орекьетте и дитали → мелкие ракушки, марсала → белое вино или амаретто.

Блюда «по мотивам книг» написаны заново своими словами: из книг взяты только идеи блюд, а количества и шаги составлены под формат приложения. Это не авторские рецепты из книг.

## Как добавить свой рецепт

Добавь объект в `recipes.js` по образцу соседних. Формат описан в комментарии в начале файла: ингредиенты — `[название, количество, единица, отдел магазина, необязательность]`, теги аллергенов, приёмы пищи, сложность 1–3, время, калории на порцию и шаги.
